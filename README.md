# Yumio

Live product: [yumio.co.uk](https://yumio.co.uk)

Yumio is a GCSE revision web app. Students can work through topics, sit exam-style questions, and use an AI tutor that can also write on a whiteboard while it explains. It started with Maths and Physics, as Combined Science.

This repository is a public write-up of the project. The product source stays private because it is a live site with user accounts.

## Stack

- HTML, CSS and JavaScript on the front end, with Tailwind CSS on some pages
- Node.js and Express on the server
- PostgreSQL via Supabase
- Hosted on Railway

The app is operated by [Prismwell Group](https://prismwell.group).
